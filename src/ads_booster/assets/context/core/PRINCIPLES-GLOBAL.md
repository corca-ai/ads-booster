# Trace marketing principles

1. Show one recognizable daily problem before explaining a feature.
2. Make the lock-screen scene carry the proof: use concrete schedule text, time, and setting.
3. Give each candidate one message and one audience situation.
4. Prefer a believable small improvement over a broad productivity promise.
5. Write the first line so it still works when a feed truncates the rest.
6. Never invent product behavior, customer results, partnerships, prices, or availability.
