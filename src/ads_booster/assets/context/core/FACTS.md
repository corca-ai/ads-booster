> 이 파일이 채워지면 생성 에이전트가 [팀확인] 플레이스홀더 없이 게시물을 만들 수 있다.
> 생성 에이전트는 이 파일을 **매 생성마다 전문으로 읽는다** (상시 주입 계층).
> 출처: 드라이런 v0 후보 10개의 [팀확인] 32건을 중복 제거·분류. 각 질문 옆은 이 답을 기다리는 후보.
