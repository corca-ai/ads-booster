# FACTS — 제품 사실 시트 v2

> 2026-08-31 재단. v1은 "화자=메이커" 정책 아래 만든 질문지였고, 컨셉 계정으로 전환하면서
> 전제가 죽어 폐기했다. 생성 에이전트는 이 파일을 **매 생성마다 전문으로 읽는다.**
> 여기 적힌 제품 사실은 전부 Trace iOS 레포 코드로 검증했다 (근거 경로는 부록).
> 규칙은 그대로다: **모르면 비워둔다. 추정으로 채우지 않는다.**

## 0. 진실 경계 — 무엇이 창작이고 무엇이 사실인가

| 층 | 규칙 |
|---|---|
| **인물** (누가 말하는가) | **창작.** 페르소나는 실재하지 않는다. 생활·감정·에피소드는 지어낸다. 다만 겪지 않은 삶이라는 사실을 글 안에서 밝히거나 암시하지 않는다. |
| **제품** (Trace가 무엇을 하는가) | **사실.** 앱이 하지 못하는 일을 했다고 쓰지 않는다. 전제 조건(요금제·단축어 설정·기기·대상)을 어긴 서술도 거짓이다. |
| **성과** (얼마나 잘 되는가) | **금지.** 사용자 수·다운로드·순위·평점·효과 수치는 근거가 없다. |

인물이 창작이라는 사실이 제품 주장까지 허용하지는 않는다. 반대로 제품 사실만 지키면 그 인물의
하루는 자유롭게 쓴다.

## 1. 기본 사실

- **Trace** — iOS 일정·할일 앱. 정식 출시. App Store 한국·일본·대만 등재.
- **앱 이름은 캡션에 쓰지 않는다.** 제품은 이미지와 동작으로만 드러난다.
- iPhone 중심. 잠금화면 배경 설정 진입점에는 아직 iPhone 가드가 남아 있다.

### 혼동하면 즉시 거짓이 되는 것 — 잠금화면은 두 가지다

| | **잠금화면 배경** | **잠금화면 위젯** |
|---|---|---|
| 정체 | 앱이 그려서 만드는 **이미지(PNG)** | WidgetKit 위젯 (accessoryRectangular / Circular) |
| 표시 | 항목당 **두 줄** — 위에 제목, 아래에 흐린 시각 | 한 줄 |
| 시각 | **`6:30AM`** 12시간제 (언어와 무관하게 영문 AM/PM) | 24시간제 `HH:mm` |
| 개수 | 칸 구성에 따라 가변, 넘치면 `+N` | **최대 3개** |
| 장식 | 제목 앞에 컬러바(일정) / 동그란 체크박스(할일) | — |
| 인터랙션 | **없음** (이미지라 탭 대상이 없다) | 체크 토글·딥링크 있음 |

우리가 만드는 이미지는 **배경** 쪽이다. 위젯의 성질을 배경에 갖다 붙이면 거짓이 된다.

## 2. 캡션이 써도 되는 동작 (앵커)

캡션은 제품을 설명하지 않는다. 장면의 전환점에 이 동작 중 **하나만** 스치게 둔다.

### A1. 아침에 폰을 드니 잠금화면에 오늘 것이 다 적혀 있다
- 전제: 앱에서 배경 설정을 저장 + 단축어 설치 + Shortcuts 자동화 생성까지 끝낸 상태
- 요금제: 기본 기능은 무료
- 거짓이 되는 때: "앱만 깔면 알아서 바뀐다" — 설치와 자동화는 사람이 직접 한다

### A2. 내 사진 위에 오늘 일정이 얹혀 있다
- 전제: A1과 같음. 사진 한 장은 무료
- 요금제: **여러 장이 돌아가며 바뀌는 것은 유료**
- 거짓이 되는 때: 무료 맥락에서 사진이 여러 장 셔플된다고 쓰는 것

### A3. 잠금화면 위젯에서 앱을 열지 않고 체크 하나를 껐다
- 전제: "예정 일정" 위젯을 잠금화면에 추가. **할일만** 체크된다. 최대 3개까지 보인다
- 요금제: 무료
- 거짓이 되는 때: **배경**에서 체크했다고 쓰는 것 / 일정을 체크했다고 쓰는 것 / 목록이 쭉 떴다고 쓰는 것

### A4. 잠금화면에서 동그라미를 눌러 바로 입력창을 열었다
- 전제: "Trace 실행" 원형 위젯 추가. 이 동작은 앱이 열린다
- 요금제: 무료

### A5. 말로 던졌더니 일정이 들어가 있다
- 요금제: **유료 전용.** 무료로는 한 건도 안 된다
- 쓸 때는 그 문장 안에서 유료로 쓰고 있음이 자연스럽게 드러나야 한다 (§4)
- 참고: 직접 입력·수정·삭제·반복 일정은 무료 무제한이다

### A6. 잠금화면에 D-100 같은 게 같이 떠 있다
- 전제: 디데이 부품 추가. 요금제: 무료 (디데이 카드에 사진을 까는 것은 유료)

### A7. 잠금화면에 올해가 얼마나 지났는지 점으로 보인다
- 전제: 부품 추가. 요금제: 도형 네 종은 무료, 동물·식물·날씨 모양은 유료

### A8. 잠금화면에 이번 달 달력이 통째로 있다
- 전제: 부품 추가. 달력이 한 줄을 독점해서 그만큼 일정 칸이 줄어든다

### A9. 지난 할일이 빨갛게 "기한 지남"으로 남아 있다
- 전제: **미완료 할일만.** 일반 일정은 빨개지지 않는다

## 3. 절대 쓰면 안 되는 문장

| 문장 | 왜 거짓인가 |
|---|---|
| "앱만 깔면 잠금화면이 알아서 바뀐다" | 단축어 설치와 자동화 생성은 사람이 한다 |
| "잠금화면 일정을 탭하니 앱이 열렸다" | 배경은 이미지다. 탭 대상이 없다 |
| "잠금화면 배경에서 체크를 껐다" | 체크는 위젯 쪽이다 |
| "잠금화면에 09:00처럼 떠 있다" | 배경의 시각은 `6:30AM` 형식이다 |
| "말로 넣으면 무료로도 들어간다" | 무료는 0건이다 |
| "잠금화면 위젯에 하루 일정이 쭉 뜬다" | 위젯은 최대 세 개다 |
| "일정도 위젯에서 체크된다" | 할일만 토글된다 |
| "저장하면 사진 앱에 자동으로 들어간다" | 앱은 이미지를 만들어 넘길 뿐이다 |
| 사용자 수·순위·평점·"○○명이 쓰는" | 근거가 없다 |

## 4. 요금제를 다루는 법

- **항목마다 무료/유료를 구분해 나열하지 않는다.** 요금제 설명은 캡션이 할 일이 아니다.
- 위에서 **유료로 표시된 동작을 쓸 때만**, 그 문장 안에서 돈을 내고 쓰고 있다는 사실이
  자연스럽게 드러나게 한다. 예: "결제하고 쓰는 중인데", "유료 켜고부터는"
- 무료로 되는 일을 굳이 "무료로 된다"고 쓰지 않는다.
- 계정을 무료용·유료용으로 나누지 않는다. 같은 사람이 필요할 때 유료 기능을 쓸 뿐이다.

## 5. 팀 결정 대기 (정해지기 전까지 캡션에서 다루지 않는다)

| # | 결정할 것 | 왜 필요한가 |
|---|---|---|
| 1 | 계정이 Trace와의 관계를 밝히는가 (프로필 표기 등) | 표시광고 이슈. 캡션이 앱을 안 가리켜도 남는 문제 |
| 2 | 댓글로 링크를 주는 운영을 누가 어떻게 하는가 | 캡션이 앱을 안 가리키므로 유입 경로가 프로필과 댓글뿐이다 |
| 3 | 이미지의 잠금화면을 실제 렌더링과 얼마나 맞출 것인가 | 지금 우리 이미지는 배경도 위젯도 아닌 제3의 형식이다 |

## 6. 확인 불가 (레포에 없다)

- **개발 계기·창업 서사** — 사람에게 물어야 한다. 제품 논리("일정 관리에 쓰는 인지 에너지의 순감소")만 있다
- **가격(원/월·원/년)** — App Store Connect에 있다
- **사용자 수·다운로드·매출·평점** — 어떤 형태로도 없다
- **잠금화면 배경에 실제로 보이는 항목 개수** — 칸 수·글자 크기·기기 크기의 함수라 단일 값이 없다. 실기 촬영으로 재야 한다
- **무료 AI 입력이 0건인가 3회/일인가** — 코드는 0, 일부 스펙 문서는 3회/일. 코드를 따랐다. 제품팀 확인 필요
