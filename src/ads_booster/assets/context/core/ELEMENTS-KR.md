# 한국 요소 판정표 (KR)

> **v1.1 정정 (2026-08-24, `research/verification-pass.md`)**
> 1. `app_name_shown` 등급 **지지 → 반증**(교란 해소). 아래 표 참조.
> 2. `tone=formal` 행의 결론이 **KR 원리 9 폐기를 이끌었다** — `PRINCIPLES-KR.md` v3 참조. 이 표의 판정이 옳았다.
> 3. `has_numbers` 행의 결론이 **원리 6 개정을 이끌었다**(숫자 → 효용 구체성). 이 표의 판정이 옳았다.
> 4. **kr-025 `views: 39`(좋아요 163)는 물리적으로 불가능한 값** — kr-021(`views: 57`/좋아요 308)과 같은 유형의 오류인데 기록돼 있지 않았다. 신규 발견.
> 5. **KR 도달 데이터의 구조적 결손**: 31건 중 27건이 `views: null`이고, 값이 있는 4건 중 2건이 위와 같이 손상됐다. **KR에서 쓸 수 있는 조회수는 kr-026(60만)·kr-027(94만) 2건뿐**이며, 도달을 논하는 KR 서술은 전부 반응 수로부터의 추론이다.
> 6. 하단 AXES 승격 후보 3건(`benefit_concreteness`·`speaker_type`·`character_present` 분리) 중 **`benefit_concreteness`와 `speaker_type`은 검증 패스가 확정 승인**했다. `is_video`를 네 번째 후보로 추가 요청한다(KR 원리 13이 이 축 부재로 검증 불가 상태).

> **요소 수준** 판정만 담는다. 포맷 수준 원리는 `PRINCIPLES-KR.md`에 있고, 중복되면 재서술하지 않고 상호 참조한다.
> 등급: **지지**(독립 계정 2건+ hit + 대조 가능한 flop/부재) / **반증** / **표본 부족**(1건 이하 또는 대조군 없음) / **판정불가**(데이터 얕음).

## 이 표가 AXES에 요청하는 것 (열린 칸 → 축 승격 후보)

1. **`benefit_concreteness`(효용 서술의 구체성)** — has_numbers가 3개국 어디서도 변별력이 없는데, 실제로 갈리는 것은 "무엇이 얼마나 좋아졌는지"의 서술 유무다. 현 AXES에 이 축이 없어 원리 6을 요소 수준에서 검증할 수 없다.
2. **`speaker_type`(화자 유형: 개인 / 메이커 / 브랜드)** — tone·empathy·app_name 세 축의 판정이 전부 "화자"에서 갈렸는데 축이 없어 분리하지 못했다.
3. **`character_present`를 background_subject에서 분리** — 캐릭터가 배경(월페이퍼)에 있는지 UI 안에 있는지가 전혀 다른 사안인데 한 칸에 뭉쳐 있다. kr-026(배경=풍경, 캐릭터=UI)이 대표 사례.
