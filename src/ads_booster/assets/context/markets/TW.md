# Taiwan starter context

- Write captions and all visible schedule text in natural Traditional Chinese.
- Build one recognizable day around classes, commuting, work, meals, exercise, or family errands.
- Use a compact, conversational first line and avoid Mainland Chinese vocabulary when a Taiwan expression is available.
- Weather and annual events are context inputs, not facts to invent; use them only when the selected situation names them.
- Reference `tw-campus-day` for a student day and `tw-city-workday` for a working day.
