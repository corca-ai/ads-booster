# 한국 장면 레퍼런스 인덱스

## kr-study-day

시험 기간에 강의, 과제, 스터디, 식사, 운동 일정이 한날에 겹치는 장면. 늦은 밤 책상이나 이른 아침 캠퍼스 배경과 어울린다.

## kr-office-day

출근, 회의, 집중 업무, 점심, 운동, 약속이 이어지는 평일 장면. 지하철 창가, 사무실 책상, 퇴근길 도시 배경과 어울린다.

## kr-shift-day

출근 시간이 일정하지 않은 교대 근무자의 인수인계, 휴식, 식사, 귀가 장면. 새벽 거리나 조용한 휴게 공간 배경과 어울린다.

## kr-family-day

등원, 병원, 장보기, 가족 식사처럼 여러 사람의 일정이 섞이는 장면. 집 현관, 주방, 동네 산책길 배경과 어울린다.
