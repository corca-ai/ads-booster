# T2 — 예정 리스트 + 할 일 리스트

가장 단순한 구성. 비숑 사례(2026-09-04)로 텍스트 교체가 검증된 레이아웃. 화면 아래 40%가 비어 배경 피사체 자리가 넓다.

## 컴포넌트와 칸 수

| 컴포넌트 | 위치 | 칸 | 비고 |
|---|---|---|---|
| 상태바 | 상단 우측 | 신호 · 와이파이 · 배터리 숫자 | 캐리어명 없음 |
| 날짜 · 시계 | 상단 중앙 | 1 · 1 | iOS 렌더. 템플릿 값 `8月27日 木曜日` / `9:42` |
| 예정 리스트 | 좌열 | `today_slots: 2` · `tomorrow_slots: 2` · `+N` | 헤더 이모지 📅 + 제목(편집 필드) |
| 할 일 리스트 | 우열 | `task_slots: 9` · `+N` | 헤더 이모지 ✅ + 제목(편집 필드). 긴 제목은 렌더 시 `…`로 잘린다 — **주문서는 전체 제목을 쓴다** (run-02 교훈) |
| 손전등 · 카메라 · 홈 인디케이터 | 하단 | — | 그대로 |

## 슬롯과 색 (v0.3 — 색은 템플릿이 보유, 주문서는 배정만)

| 슬롯 | 자리 | 막대 색 (템플릿 원본) |
|---|---|---|
| today-1 | 예정 오늘 1행 | 분홍 (家族旅行) |
| today-2 | 예정 오늘 2행 | 청록 (下半期戦略合宿) |
| tomorrow-1 | 예정 내일 1행 | 초록 (ストレッチ) |
| tomorrow-2 | 예정 내일 2행 | 초록 (登山キャンプ) |
| task-1~9 | 할 일 | 파란 빈 원 (전부 동일) |

프롬프트에는 색을 쓰지 않는다. "같은 종류 → 같은 색 슬롯" 배정은 주문서 ⓒ에서.

## 배경 사양 값

- `text_bottom: 58` — 글자 하한선(참고값). v0.3은 여백 채우기라 하한선이 아니라 **글자 회피**가 기준. 하단 42%는 주 모티프 자리

## 주문서에 필요한 데이터

- 주간 일정 중 D+0 · D+1 (각 2개 보임 + 숨김 수)
- 할일 8~12 (9개 보임 + 숨김 수)
- 헤더 제목 2개 (KR 기본 `일정` / `할 일`)
