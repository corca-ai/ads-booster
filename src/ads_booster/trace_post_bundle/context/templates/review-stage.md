# 단계별 검수 기록 형식

각 이미지 시도마다 작성한다. 예전 run-02에 없던 관찰을 나중에 지어내 채우지 않는다.

- call_id:
- 단계 / 국가 / 시도 번호:
- 입력 이미지 / 출력 이미지 / 주문서 / 실제 프롬프트 경로:
- 검수자 모델:

| 항목 | 판정: 통과/반려/미확인/해당 없음 | 실제 관찰 | 근거 위치·문구 |
|---|---|---|---|
| 해당 단계 규칙의 모든 항목을 각각 작성 | | | |

- A: IMAGE-RULES §5 A 1~8. T3 전용은 해당 없음. 기하 명령·출력·종료 코드 첨부.
- B: A 1~8 재대조 + 9~12. 배경 기하 검수는 시각 비교.
- L: 주문서 문자열 / 잔상 / 긴 제목 / 슬롯·색·배치 / 배경 보존 / 날짜·시각·+N.
- C: ①~⑩를 각각 작성. ⑩은 반려 조건이 아닌 관찰. ⑨는 읽히는 문자열을 실제 주문서와 대조.
- 육안 디자인 동일성: 판정·차이. 픽셀 동일성: 측정 방법·결과, 측정하지 않았으면 미측정.
- 단계 판정: 통과/반려/미확인. 반려는 규정된 1회 재시도, 미확인은 사용자 검토 대상으로 보류.
- 채택한 출력과 이유 / 남은 관찰 / 다음 단계 가능 여부:

손·네일·의복 세부의 국가 간 차이는 허용한다. 추가 소품이나 환경 글자가 IMAGE-RULES C ④·⑦ 범위 안에 있는지는 별도로 판정한다.
