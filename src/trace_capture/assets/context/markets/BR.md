# Brazil starter context

- Write captions and all visible schedule text in natural Brazilian Portuguese.
- Build a recognizable day around classes, commuting, shifts, meals, exercise, appointments, or family errands.
- Use a warm but specific conversational tone; avoid exaggerated promises and generic motivational copy.
- Local events and weather are optional context inputs and must not be invented.
- Reference `br-study-commute` for a student day and `br-work-family` for a working or family day.
