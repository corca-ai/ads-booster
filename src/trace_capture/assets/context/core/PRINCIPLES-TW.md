> **시딩 격리**: tw-004/015(Taska, 인센티브·앰버서더 태그 확인)는 조직적 시딩 정황이 있어 원리의 단독 근거로 쓰지 않았다.

## ⚠️ relative 지표 주의 (v2 신설)

**TW의 `relative`는 KR·JP와 계산식이 다르다.** TW 레코드 17/18이 `quotes`를 반응 합계에 포함하는데 KR(0/31)·JP(3/32, 값 무시 가능)는 포함하지 않는다. TW의 quotes는 작지 않다(tw-003 1,100 / tw-014 1,300 / tw-002 1,000). **TW relative는 KR·JP 대비 1.2~2.2배 부풀려져 있다.**

KR·JP 호환 값: tw-002 4.00→**1.86** / tw-003 0.024→**0.013** / tw-013 11.7→**6.42** / tw-014 19.06→**11.09** / tw-001 630.3→**516.7**.

**국가 간 relative 숫자를 나란히 놓지 말 것.** 아래 원리들은 대부분 within-account 대조에 기반하므로 계산식과 무관하게 성립한다. (상세: `research/verification-pass.md` §0-2)

## 캡션

1. **죽이는 것은 계정 유형도 어투도 아니라 화자 구조다 — 발화의 주어가 사람이면 살고, 제품·조직이면 죽는다.** (v2 재서술)

   TW는 3국 중 유일하게 **양방향 분리 사례를 모두 갖고 있어** 이 원리를 확정한 나라다.
   - **브랜드 계정 + 개인 발화 → 산다**: tw-002(WEiZ 리테일, 수달 마스코트 1인칭 "－🦦" 서명 / 계정 평소 좋아요 1~10 → **726**), tw-003(蘋果仁 팔로워 9.8만 미디어, "이 방법 진짜 편함" 실사용 톤 / 평소 4~14 → **1,200**, 100배)
   - **개인 계정 + 조직 발화 → 죽는다**: **tw-012**(1인 개발자 계정 팔로워 471인데 캡션이 「PickUp 取貨吧 v1.7.0 更新內容」— **1인칭이 한 번도 안 나오는 릴리즈 노트**, rel 0.021 = 같은 계정 자기소개 게시물의 **1/15**)

   tw-012가 결정적이다. 계정 유형과 발화 구조를 깨끗하게 분리하는 코퍼스 유일의 레코드다 — 개인 계정이어도 발화가 조직화되면 죽는다.

   **판정 규칙**: 캡션 주절의 주어가 (a) 실재하는 1인칭 사람이면 개인 발화, (b) 제품명·버전·조직이면 조직 발화. 계정 유형과 어투는 보지 않는다. → `PRINCIPLES-GLOBAL.md` 원리 5.
2. **메이커 계정은 서사(성취·실패·발견)가 있는 날에만 도달한다. 일상/루틴 공지는 이미지 품질과 무관하게 거의 안 뜬다.** 서로 다른 두 계정에서 within-account 통제 대조로 재현. (dayblocks: 출시 tw-008 rel 6.0 vs 일상잡담 tw-017 rel 0.43 — 14배 / ethanhuang13: 실패담 tw-010 rel 0.153 vs 정기업데이트 tw-018 rel 0.0055 — 28배)

   **v2 보강 — 갈리는 것은 참여율이 아니라 도달이다.** 두 쌍을 조회수까지 열어보면 저동력 게시물은 관객에게 외면당한 것이 아니라 **알고리즘이 배포하지 않았다.**

   | 쌍 | 조회 | 반응 | 조회당 반응 |
   |---|---|---|---|
   | tw-008 (출시 성취) | 3,400 | 42 | 1.2% |
   | tw-017 (일상 잡담) | **67** | 3 | **4.5%** |
   | tw-010 (실패담) | 45,000 | 473 | 1.1% |
   | tw-018 (정기 업데이트) | **766** | 17 | **2.2%** |

   조회가 **50~59배** 갈렸고 조회당 반응은 오히려 저동력 쪽이 높다. 즉 "안 좋아서 반응이 없는" 게 아니라 **소재가 없으면 배포 자체가 안 된다.**

   **표본 경고**: tw-017은 반응 총합 **3건**(팔로워 7)으로 단독으로는 노이즈다. 이 원리는 실질적으로 tw-010/018 쌍(반응 473 vs 17)이 떠받친다.

   **GLOBAL 승격 검토 결과 — 별도 원리로 올리지 않는다.** 이 원리의 근거(위 두 쌍)는 이미 `PRINCIPLES-GLOBAL.md` 원리 2의 TW 다리로 인용돼 있어 별도 원리로 세우면 이중 계상이 된다. tw-017의 `transferable`도 스스로 "훅의 동력 중 하나를 확보한 날에만 게시"라고 적어 GLOBAL 원리 2의 적용례임을 밝힌다. → GLOBAL 원리 2의 **운영 규칙**으로 흡수됨.
3. **자조적·솔직한 톤이 노골적 판매 어투보다 강하다.** 廢文 문화의 함의가 확인됨. (tw-011 "토큰 태워 만든 잡탕앱" 자조 톤, 조회 10만·좋아요 1천 / tw-007 "살짝 복잡했지만 한번에 성공" 솔직 시행착오, rel 28.0)
   - **v2 — 반례 쪽 근거가 약하다.** tw-016(노골 판매어투 + 무관 소재)의 rel 0.19는 **계정 간 정규화가 만든 값이지 성능 저하의 증거가 아니다**. 레코드 자체가 "평소 게시물은 좋아요 2~14개 수준. 이 광고성 게시물도 크게 다르지 않은 반응(7개)"이라 적고 있다 — **within-account로는 flop이 아니라 평소 수준**이다. tw-004는 시딩 격리 대상이라 단독 근거로 못 쓴다.
   - 따라서 이 원리의 긍정형(자조 톤이 강하다)은 tw-011·tw-007로 지지되지만, **부정형(판매 어투가 죽인다)은 TW 데이터로 확정되지 않는다.**
4. **팔로워 수는 도달의 상한이 아니다 — 한국·일본보다 더 극단적이다.** (tw-001 팔로워3명 rel **630.3**, tw-007 팔로워5명 rel 28.0, tw-013 팔로워69명 rel 11.7, tw-014 팔로워163명 rel 19.06, tw-008 팔로워7명 rel 6.0)
5. ~~**완결된 리스트라도 항목 하나하나가 논쟁거리면 댓글이 크게 온다.**~~ → **v2에서 원리 강등, 가설로 이동.** (tw-009 30세 목표 8개 선언, 항목마다 반박 댓글 → 댓글비 0.17로 계정 역대 최고 히트)
   - **"KR 원리 2의 반례"라는 서술은 오독이었다 — 삭제한다.** KR 원리 2의 실제 문장은 "여백 원리는 **질문형 훅에만** 적용된다 / 데모형은 답을 다 줘도 뜬다(kr-026, kr-030, kr-031)"로, **이미** 비질문형 완결 게시물의 성공을 허용한다. tw-009는 `hook_type=declaration`이므로 KR 원리 2가 예측하는 대로 행동한 것이지 반한 것이 아니다. **KR 원리 2는 수정할 필요가 없다.**
   - **진짜 새 주장("논쟁성이 여백을 대체한다")은 표본 1건**으로 이 파일의 채택 기준(독립 2건) 미달이다. 게다가 KR에 반대 방향 증거가 있다 — kr-002(질문형, 댓글 **369**) vs kr-004(답변 나열 완결, 댓글 **2**)는 팔로워 규모가 거의 같은데(6,874 vs 6,732) 30배 갈렸다. 완결 리스트가 자동으로 댓글을 부르지는 않는다.
   - 남는 정교한 가설: "완결 리스트 중 **반박 가능한 주장**을 담은 것만 댓글이 온다"(tw-009는 월수입 500만·주 10시간 노동 같은 도발적 목표, kr-004는 합의 가능한 처세술 팁). 각 방향 1건씩이라 **확정 불가** → `PRINCIPLES-GLOBAL.md` 검증 대기 가설로 이관.
6. **제품 얘기보다 사람의 서사(목표선언·실패담)가 계정 최고 히트가 된다.** 제품 출시 이전이어도 유효. (tw-009 목표선언 948좋아요 — 계정 역대 최고, 이후 실제 앱 개발로 이어짐 / tw-010 12파트 실패담 스레드 — 계정 역대 최고, 343좋아요)

## 이러면 죽는다

- **설정 화면만 보여주고 완성된 결과를 안 보여줌** (tw-012)
- **노골적 판매 어투 + 무관한 소재(팬덤 등) 결합** (tw-016 "필수 다운로드", 별 5개, 해시태그 스팸)
- **서사 없는 일상/루틴 공지** — 같은 계정도 출시·성취·발견이 없는 날은 죽는다 (tw-017, tw-018)
- **인센티브를 명시한 자기홍보형 CTA**("좋아요 늘면 리워드") — 시딩 티가 나면 반응이 오히려 낮다 (tw-004 rel 0.053)

## 성패를 가르지 않는 것

- **리스티클 vs 단일 소재 딥다이브**: tw-005(Day100, 10개 리스티클)가 같은 계정의 단일 도구 딥다이브(Day89)보다 약해 보이나 딥다이브 쪽 relative가 미검증이라 비교 불가 — **관찰로만 기록, 원리 아님.**
- **캐릭터·마스코트**: tw-002(WEiZ 수달)가 브랜드 개인화에 기여했을 가능성이 있으나 반례 표본이 없어 인과 미검증.

## 포지셔닝 경고 (competitors.md·TW-log 반영)

- **Taska가 이미 대만 Threads 잠금화면 클러스터를 상당 부분 장악**했다 — 다수의 독립 계정이 유기적으로 언급(tw-006), 동시에 공식 캠페인형 시딩도 확인(tw-004, tw-015). 앱 이름 자체가 "任務App"(할일 앱)으로 소개되는 경우가 많아, 일본과 마찬가지로 **「行事曆/일정」 문법으로 차별화해야 한다.**
