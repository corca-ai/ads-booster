# 대만 요소 판정표 (TW)

> **v1.1 정정 (2026-08-24, `research/verification-pass.md`)**
> 1. **TW 18건 전수의 relative를 원본 metrics로 재계산한 결과 18/18 일치** — kr-012형 산술 오기재는 TW에 없다. 태깅 표본 9건 대조에서도 명백한 오류 0건.
> 2. **그러나 relative의 계산식이 국가마다 다르다.** TW 17/18이 `quotes`를 포함하고 KR(0/31)·JP(사실상 0)는 포함하지 않아 **TW relative가 1.2~2.2배 부풀려져 있다.** 아래 국가 차이 §1의 relative 비교와 `PRINCIPLES-TW.md` 상단 주의 참조. **국가 간 relative 숫자를 나란히 놓지 말 것.**
> 3. 의심 태깅 3건(확정 오류 아님): tw-012 `bg_subject=none`(월페이퍼 소재 미기술이므로 `?`가 맞다) / tw-016 `cta=direct_link`(「App Store 🔍 Taska」는 검색 지시이지 링크가 아니다) / tw-016 `dev_real=staged`(실기기 화면 녹화라 `high`가 더 맞다).
> 4. `has_numbers` 행의 3국 공통 결론이 **JP 원리 4·KR 원리 6 개정을 이끌었다**(숫자 → 효용 구체성).

> **요소 수준** 판정만 담는다. 포맷 수준 원리는 `PRINCIPLES-TW.md`, 중복은 상호 참조로 대체.
> 등급 정의는 `ELEMENTS-KR.md` 상단과 동일.
> **시딩 격리**: tw-004 / tw-015(Taska 캠페인)는 판정 근거에서 제외. 격리 후 유효 표본 **16건** — 3개국 중 가장 얇다.

## 국가 차이 (요소 수준)

1. **length** — TW long 5/6 hit(독립 5계정), 계정 최고 히트 2건이 장문 텍스트 전용. KR long 4/6, JP long 2/3(n=3). 대만은 긴 서사를 읽는 시장이다.
2. **hook_type = empathy** — TW 2/2 hit vs JP 2/2 flop vs KR 2:2. 세 나라에서 가장 크게 갈리는 캡션 요소.
3. **mood** — TW만 무드가 성패와 무관하다(clean 6:2, busy 2:0으로 방향성 없음). KR·JP는 각각 warm·cute로 뚜렷하다.

## 표본 한계 (읽는 사람이 반드시 알아야 할 것)

TW는 18건 중 2건이 시딩 격리, 2건이 텍스트 전용이라 **이미지 요소의 유효 표본이 14건**이다. 위 표에서 `표본 0건`으로 남은 칸(캐릭터 배경 / face / question·demo 훅 / repost)은 "TW에서 안 통한다"가 아니라 **"아직 안 봤다"**는 뜻이다. `research/elements-gaps.md` ⓐ 참조.
